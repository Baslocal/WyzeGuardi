ℹ️ How Schedules Work

Priority: Custom schedules are checked first. If no matching schedule is found, the system falls back to the default weekday/weekend schedule.

Days: 0=Monday, 1=Tuesday, 2=Wednesday, 3=Thursday, 4=Friday, 5=Saturday, 6=Sunday

Time Window: During the specified time window, cameras will be set to the chosen state (ON or OFF).

Enabled: Only enabled schedules are active. Disabled schedules are kept but not used.
